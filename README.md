# ORVUNO – Wirtschaftssimulation im Browser

ORVUNO ist eine fortlaufende Wirtschaftssimulation von Nadena Games. Spieler führen Betriebe und verbinden Einkauf, Lieferanten, Lager, Personal, Maschinen, Produktion, Abfüllung, Kundenaufträge, Logistik, Markt und Finanzierung zu einem wachsenden Unternehmen.

## Projekt

Die Spielwelt wird laufend weiterentwickelt. Technische Änderungen, Balancing-Entscheidungen, neue Systeme und Deployment-Anpassungen werden im Repository dokumentiert.

## Chat-Kontinuitätsregel

Diese README und die zugehörigen Projektdateien auf GitHub sind die dauerhafte Wissensquelle für spätere ChatGPT-Chats zu diesem Spiel.

Wenn in einem Chat neue verbindliche Spielideen, Änderungen, Balancing-Entscheidungen, technische Architekturentscheidungen, neue Systeme, Umbenennungen oder Deployment-Änderungen beschlossen werden, sollen sie ohne zusätzlichen Hinweis des Nutzers im selben Arbeitsgang in der Projektdokumentation auf GitHub ergänzt werden.

Ein neuer Chat soll vor größeren Arbeiten zuerst die aktuelle README bzw. die verlinkten Projektdateien lesen und auf diesem Stand weiterarbeiten, statt frühere Entscheidungen zu erraten oder neu zu erfinden.

Nicht jede spontane Idee ist automatisch verbindlich. Gespeichert werden bestätigte Entscheidungen und klar als Projektbestandteil formulierte Änderungen.
